## Release v0.3.0 — Lifecycle Supervision & Physical Verification

The `v0.3.0` release introduces the `memoria run` out-of-band lifecycle supervisor and the **"Don't Trust Exit 0"** physical verification engine.

- **Audited Project Target**: `memoria-v0.3.0`
- **Ledger Database**: `docs/v0.3.0_provenance.db`
- **Interactive Visualizer**: `docs/v0.3.0_provenance.html`
- **Chain Status**: `HASH CHAIN VALID (3 BLOCKS) — Zero Tampering Detected`
- **Maintainer / Attribution**: Mallard Unified Industries ([https://www.mallard.ink](https://www.mallard.ink))

### Goals Implemented in v0.3.0

| # | Milestone Goal | Mechanism & Implementation | Status |
|---|---|---|:---:|
| 1 | **`memoria run` Subcommand** | Dedicated out-of-band supervisor wrapping untrusted agent execution with pre-flight, wiretap interception, and post-flight physical auditing. | **VERIFIED** |
| 2 | **"Don't Trust Exit 0" Engine** | Rejection of agent completion claims based solely on process exit codes; enforcement of ground-truth test execution predicates. | **VERIFIED** |
| 3 | **Independent Host Verification (`--verify-cmd`)** | Independent test/build command execution in a clean host environment outside the agent's reach. | **VERIFIED** |
| 4 | **Ledger Action Auditing (`--require-tests`)** | Physical ledger inspection scanning `task_ledger` for verified executions of test binaries (`cargo test`, `pytest`, `npm test`, etc.) with exit code `0`. | **VERIFIED** |
| 5 | **Issue Lifecycle Synchronization (`--issue <id>`)** | Automated GitHub Issue markdown ledger comments and checklist closing via `gh` CLI. | **VERIFIED** |
| 6 | **Air-Gapped Flight Report Auto-Generation** | Automatic generation and export of standalone HTML flight reports upon supervised task completion. | **VERIFIED** |
| 7 | **Adversarial Test Suite** | Integration tests verifying that an agent exiting `0` without running tests is caught and rejected by the audit engine. | **VERIFIED** |
